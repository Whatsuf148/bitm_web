The Basic Git Workflow

  1. git clone <repo-url> — copy the project to your computer
  2. git checkout -b my-branch — make your own branch
  3. Edit a file (try adding your name in script.js!)
  4. git add . — stage your changes
  5. git commit -m "Add my name" — save a snapshot
  6. git push origin my-branch — send it to GitHub
  7. Open a Pull Request on GitHub 🎉
